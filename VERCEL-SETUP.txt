NORTHWELD GAMES, VERCEL WEBHOOK SETUP

1. Upload or redeploy this COMPLETE project folder in Vercel.
2. Do not upload only OPEN-ME.html or only the public folder.
3. Open the Vercel project.
4. Go to Settings > Environment Variables.
5. Create an environment variable named DISCORD_WEBHOOK_URL.
6. Paste the Discord application webhook as its value.
7. Select Production, Preview and Development.
8. Save the variable.
9. Open Deployments and redeploy the latest deployment.
10. Open https://YOUR-DOMAIN/api/health.

The result must contain:
"applicationsConfigured": true

If it says false, the webhook variable is missing, invalid, or the project was not redeployed.
